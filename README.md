# Cravernau - React Setup

Este proyecto se creó desde cero (sin código previo en el workspace).

## Qué incluye
- App React (Vite)
- Vista principal (Home/Landing)
- Dependencias instaladas

## Ejecutar
```bash
npm install
npm run dev
```

## Variables en Vercel

Para generar titulares y descripciones con Gemini, configura estas variables de entorno en Vercel:

```bash
GEMINI_API_KEY=tu_clave_gemini
GEMINI_MODEL=gemini-3.5-flash
```

`GEMINI_MODEL` es opcional. Si no se configura, se usa `gemini-3.5-flash`.

## Notas
Si deseas que la UI/estructura sea distinta, indícame el nombre de la página principal y el estilo deseado.
